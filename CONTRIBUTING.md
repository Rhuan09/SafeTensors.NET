# Contributing to SafeTensors.NET

## Getting set up

Requires the .NET 10 SDK. The library multi-targets `netstandard2.0`, `net8.0` and
`net10.0`; the SDK pulls the older reference packs for you.

```bash
dotnet build
dotnet test                                                  # what CI runs
dotnet run -c Release --project samples/SafeTensors.Sample   # a tour of the API
dotnet run -c Release --project benchmarks/SafeTensors.Benchmarks
```

## Branching

`main` is always releasable. Never commit to it directly — every change goes through a pull
request, including your own.

Whether GitHub *enforces* that is a repository setting, not something this file can
guarantee. To require PRs and a passing CI check before anything lands on `main`:

```bash
gh api -X POST repos/:owner/:repo/rulesets --input .github/rulesets/main.json
```

Branch names are `<type>/<short-kebab-description>`:

| Prefix | For |
| --- | --- |
| `feat/` | A new capability |
| `fix/` | A bug in existing behaviour |
| `perf/` | A measured performance change, with the benchmark output in the PR |
| `docs/` | Documentation only |
| `refactor/` | Structure change with no behaviour change |
| `chore/` | Build, CI, dependencies, tooling |

Keep one concern per branch. A new dtype and a change to the validation rules are two PRs —
the second one deserves review on its own.

## Commits

Present tense, imperative, explaining *why* when it isn't obvious from the diff:

```
Reject tensors whose byte ranges overlap

Two names claiming the same bytes is not something an honest producer
writes, and accepting it lets one crafted file hand the same memory to
two consumers that each believe they own it. Ranges are now sorted by
start offset and checked to tile the data section.
```

## The rules that are not negotiable

**Validation is strict by default.** A checkpoint is untrusted input. New leniency is a new
opt-in property on `SafeTensorReadOptions`, never a change to what the defaults accept. If
you find a real file the reader rejects, that is a good bug report — the fix is still a
flag.

**Nothing but `SafeTensorException` leaves the parser.** Header parsing is full of places
where `JsonElement` throws `InvalidOperationException` for a value of the wrong kind. Every
one of them gets converted. A caller who writes `catch (SafeTensorException)` has covered
the surface.

**Public API does not hand out unsafe things quietly.** Anything that returns a pointer or a
span whose validity is tied to something else says so in its name or its XML docs. The
lifetime rules are in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md); changing them needs a
reason in the PR description.

**The hot paths do not allocate.** `AsSpan`, `AsMemory` and `Slice` are the reason this
library exists. If a change makes one of them allocate, the benchmark output belongs in the
PR along with the reason it is worth it.

**No new NuGet dependency on modern TFMs.** The library has none today and that is a
feature. netstandard2.0 polyfills are the exception.

## Tests

New behaviour needs a test, and bug fixes need one that fails before the fix. Tests live
next to what they cover:

| File | Covers |
| --- | --- |
| `HeaderValidationTests` | Malformed and hostile headers |
| `ReadingTests` | The three storage backends, and files from the reference implementation |
| `WritingTests` | Round trips, atomic replace, duplicate detection |
| `TensorViewTests` | Spans, windows, slices, conversions |
| `ShardingTests` | Multi-file models, path traversal, concurrency |
| `NumericsTests` | `Float16` and `BFloat16` against `System.Half` |

`tests/SafeTensors.Tests/Infrastructure/Fixture.cs` builds files byte by byte, including
ones the writer would refuse to produce. Most validation tests need that.

Fixtures live in `TestFiles` and are all regenerated by `TestFiles/genTests.py`:

```bash
python -m pip install numpy safetensors ml_dtypes
python tests/SafeTensors.Tests/TestFiles/genTests.py
```

The `reference_*` files come from the Hugging Face `safetensors` package, so the reader is
checked against bytes a real producer emitted. A round-trip test only proves the writer and
the reader agree with each other. The `malformed_*` files are assembled byte by byte,
because no honest producer emits them and the reference implementation refuses to.

Add new fixtures to that script rather than committing a binary nobody can reproduce.

## Adding a dtype

1. Add the enum member to `SafeTensorDType`.
2. Add its bit size to `DTypes.BitSize`, its name to `DTypes.ToHeaderString`, and its
   parse cases to `DTypes.TryParse`.
3. Add the numeric value to `safetensors.h` — the native ABI passes dtypes as integers, so
   the two must not drift.
4. Round-trip it in `WritingTests.Round_trips_every_dtype_that_has_a_clr_type`, or add a
   raw-bytes test if it has no CLR counterpart.

Sub-byte types will need `DTypes.ByteLength` to round up from bits rather than divide. The
API is shaped for that; nobody has needed it yet.
